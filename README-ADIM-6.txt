# 501 Otomotiv - 6. Adım

Bu paket, GitHub repository'sindeki `data/site.json` dosyasını ve ilan fotoğraflarını GitHub API üzerinden yönetmek için hazırlanmış yönetim panelidir.

## Kullanım
1. `admin.html`, `admin.css`, `admin.js` dosyalarını repository köküne yükleyin.
2. `data/site.json` dosyasını yükleyin.
3. Site adresinde `/admin.html` açın.
4. GitHub kullanıcı adı, repository ve Fine-grained tokenı panele kendiniz girin.
5. Token tarayıcıda saklanmaz ve dosyalara yazılmaz.

## Önemli
Bu bir istemci tarafı yönetim aracıdır. Gerçek kullanıcı adı/şifre güvenliği sağlamaz. Tokenı yalnızca güvendiğiniz cihazda kullanın. Tokenı public kod içine koymayın.
